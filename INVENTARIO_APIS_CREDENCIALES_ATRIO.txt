3. APPLE DEVELOPER PROGRAM (SIGN IN WITH APPLE)
--------------------------------------------------------------------------------
Para permitir el inicio de sesión oficial en dispositivos iOS conforme a los
lineamientos obligatorios de la App Store de Apple.

- Service ID actual (Personal):
  org.atrio.app.signin

- Archivos donde se utiliza en el código:
  * lib/data/app_config.dart (AppConfig.appleServiceId)
  * lib/screens/inicio_sesion_screen.dart (en la llamada a SignInWithApple.getAppleIDCredential)

- Qué debe tramitar el equipo:
  1. Cuenta institucional en Apple Developer (Team ID de la organización).
  2. Habilitar la capacidad "Sign in with Apple" en el App ID de la aplicación iOS.
  3. Crear un "Service ID" institucional (ej. com.atrio.app.signin o org.atrio.app.signin).
  4. Configurar el dominio web verificado y la URL de retorno (Redirect URI) apuntando al endpoint de autenticación de Odoo (ej. https://erp.atrio.org/api/v1/auth/apple/callback).
  5. Generar la clave privada de Apple (.p8) para que el backend de Odoo verifique criptográficamente el token generado por Apple.

5. ENDPOINTS Y SERVIDOR BACKEND ODOO 19
--------------------------------------------------------------------------------
La aplicación móvil se conecta con la instancia ERP de Odoo para autenticación,
gestión de cuentas, donaciones y anuncios.

- URLs de Servidor configuradas:
  * Staging/Pruebas: https://staging-erp.atrio.org
  * Alternativa/Referencia: https://odoo.atrio.app
  * Base de datos: atrio_staging (o la BD de producción que corresponda)

- Archivo central de configuración:
  lib/data/app_config.dart (baseUrl, database)

- Endpoints consumidos por ATRIO:
  1. Autenticación Social (Google y Apple):
     POST /api/v1/auth/social_login
     Recibe: provider ("google" | "apple"), token, email, name, apple_user_id.
     Retorna: Datos del usuario, token de sesión y estado.

  2. Eliminación de Cuenta (Requerimiento estricto de Apple App Store):
     POST /api/v1/user/delete_account
     Recibe: Identificador o token del usuario autenticado.

  3. Anuncios y Noticias Públicas:
     GET /api/v1/anuncios/publicos
     Retorna: Lista de noticias, eventos y anuncios de la congregación.

  4. Donaciones y Pagos:
     Integración con pasarelas de pago (sale.order / pagos en línea de Odoo).
